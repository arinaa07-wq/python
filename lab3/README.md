### Методы списков 
## 1. .append(x) - добавить в конец
~~~python
stack = [1, 2, 3]
stack.append(4)
print(stack)  # [1, 2, 3, 4]
~~~~
Добавляет элемент x в конец списка.

Изменяет исходный список.

Всегда добавляет только один элемент.
## 2 .pop(i) - удалить по индексу
~~~python
stack = [1, 2, 3, 4]
last = stack.pop()     # удаляет последний (индекс -1)
print(last)   # 4
print(stack)  # [1, 2, 3]

elem = stack.pop(1)    # удаляет элемент с индексом 1
print(elem)   # 2
print(stack)  # [1, 3]
~~~
Без аргумента удаляет последний элемент.

С числом удаляет элемент по указанному индексу.

Возвращает удаленный элемент.

## .remove(x) - удалить по значению
~~~python
fruits = ['яблоко', 'банан', 'апельсин']
fruits.remove('банан')
print(fruits)  # ['яблоко', 'апельсин']
~~~
Удаляет первое вхождение элемента со значением x.

Не возвращает ничего (None).

Ошибка, если элемента нет.

## .insert(i, x) - вставить по индексу
~~~python
nums = [1, 2, 4]
nums.insert(2, 3)  # на позицию 2 вставить 3
print(nums)  # [1, 2, 3, 4]

nums.insert(0, 0)  # в начало
print(nums)  # [0, 1, 2, 3, 4]
~~~
