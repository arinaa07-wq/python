### Методы списков 
## 1. .append(x) - добавить в конец
~~~python
stack = [1, 2, 3]
stack.append(4)
print(stack)  # [1, 2, 3, 4]
~~~~
Добавляет элемент x в конец списка.

Изменяет исходный список.

Всегда добавляет только один элемент.
## 2 .pop(i) - удалить по индексу
~~~python
stack = [1, 2, 3, 4]
last = stack.pop()     # удаляет последний (индекс -1)
print(last)   # 4
print(stack)  # [1, 2, 3]

elem = stack.pop(1)    # удаляет элемент с индексом 1
print(elem)   # 2
print(stack)  # [1, 3]
~~~
Без аргумента удаляет последний элемент.

С числом удаляет элемент по указанному индексу.

Возвращает удаленный элемент.

## 3 .remove(x) - удалить по значению
~~~python
fruits = ['яблоко', 'банан', 'апельсин']
fruits.remove('банан')
print(fruits)  # ['яблоко', 'апельсин']
~~~
Удаляет первое вхождение элемента со значением x.

Не возвращает ничего (None).

Ошибка, если элемента нет.

## 4 .insert(i, x) - вставить по индексу
~~~python
nums = [1, 2, 4]
nums.insert(2, 3)  # на позицию 2 вставить 3
print(nums)  # [1, 2, 3, 4]

nums.insert(0, 0)  # в начало
print(nums)  # [0, 1, 2, 3, 4]
~~~
Вставляет элемент x на позицию i.

Все элементы сдвигаются вправо.

## 5 .extend(iterable) - добавить несколько
~~~python
a = [1, 2]
a.extend([3, 4])
print(a)  # [1, 2, 3, 4]

# То же самое что:
a = [1, 2]
a += [3, 4]
~~~
Добавляет все элементы из коллекции в конец.

Аналог +, но изменяет исходный список.

## 6 .index(x) - найти позицию
~~~python
nums = [10, 20, 30, 20]
print(nums.index(20))     # 1 (первое вхождение)
print(nums.index(20, 2))  # 3 (искать с индекса 2)
~~~
Возвращает индекс первого вхождения x.

Можно указать начало и конец поиска.
## 7 .count(x) - подсчитать вхождения
~~~python
nums = [1, 2, 2, 3, 2, 4]
print(nums.count(2))  # 3
print(nums.count(5))  # 0
~~~
Сколько раз встречается элемент x
## 8 .sort() - сортировка
~~~python
nums = [3, 1, 4, 2]
nums.sort()
print(nums)  # [1, 2, 3, 4]

nums.sort(reverse=True)
print(nums)  # [4, 3, 2, 1]

# Для строк
words = ['banana', 'apple', 'cherry']
words.sort()
print(words)  # ['apple', 'banana', 'cherry']
~~~
Сортирует список на месте (изменяет исходный).

Параметр reverse=True для обратного порядка.
## 9 .reverse() - разворот
~~~python
nums = [1, 2, 3]
nums.reverse()
print(nums)  # [3, 2, 1]
~~~
Переворачивает список задом наперед
## 10 .clear() - очистка
~~~python
nums = [1, 2, 3]
nums.clear()
print(nums)  # []
~~~
Удаляет все элементы из списка
## 11 .copy() - копирование
~~~python
a = [1, 2, 3]
b = a.copy()  # создает независимую копию
b.append(4)
print(a)  # [1, 2, 3]
print(b)  # [1, 2, 3, 4]
~~~
Создает поверхностную копию списка

### Что такое рекурсия
Рекурсия — это когда функция вызывает саму себя внутри своего кода.
## Правила рекурсии
Базовый случай — условие остановки (когда рекурсия заканчивается)

Рекурсивный случай — вызов функцией самой себя

Пример рекурсии:
~~~python
def factorial(n):
    if n <= 1:  
        return 1
    else:
    return n * factorial(n - 1)  # РЕКУРСИЯ

print(factorial(5))  # 120
~~~~
## Чем заменить рекурсию?
Рекурсию можно заменить обычным циклом + стеком (списком).

Когда использовать способы:
Рекурсия-Код короче, легко читать

Стек-Глубокие вложенности (больше 1000 уровней)

Очередь-Важен порядок обработки

Простой цикл-Только плоские списки

Примеры замены:
## Стек
~~~python
def count_items_stack(lst):
    total = 0 #переменная считающая элеменеты 
    stack = [lst]  # кладём список в стек (В Python нет встроенной функции или типа данных "stack". Это просто название переменной.)
    
    while stack: #пока в стеке есть элементы (пока он не пустой)
        current = stack.pop()  # берём последний
        for item in current: # берём каждый элемент из списка current по очереди
            if isinstance(item, list): # проверяет является ли item списком
                stack.append(item)  # добавляем этот вложенный список в конец стека
            else:
                total += 1 #Просто увеличиваем счётчик на 1
    return total

my_list = [1, [2, 3], [4, [5, 6]], 7]
print(count_items_stack(my_list))  # 7
~~~
Почему код НЕ рекурсия? Потому что в нем нет строки, где функция вызывает саму себя
~~~python
if isinstance(item, list):
    stack.append(item)  # ← Просто добавляем в список!
    # НИКАКОГО вызова count_items_stack() здесь нет!
~~~

if isinstance(item, list):
