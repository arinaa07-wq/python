# Лабороторная работа №8

## Задание
Разработать интерактивное приложение-календарь, которое позволяет пользователю управлять событиями и сохранять все данные в базе данных.

## Ход выполнения работы

1. Разработана структура проекта
Созданы файлы: main.py (интерфейс), database.py (работа с БД), exceptions.py (исключения).

2. Созданы собственные исключения
Реализованы классы: CalendarError, DateSelectionError, DateFormatError, DatabaseError.

3. Реализована работа с БД SQLite
Написаны функции: добавление, получение, удаление событий, поиск по тексту.

4. Разработан графический интерфейс
Создан класс CalendarApp с виджетами: календарь, поле ввода, кнопки (добавить, очистить, удалить, найти).

5. Реализована логика работы
Написаны методы: отображение событий при выборе даты, добавление, удаление всех, удаление одного, поиск.

6. Добавлена обработка ошибок
Все методы используют try-except и собственные исключения.
