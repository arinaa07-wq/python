# Лабороторная работа №6

## Задание 
Разработать приложение на Python с использованием PySide6 для расчета расхода топлива, времени поездки и стоимости топлива. Результаты расчетов сохранять в базу данных PostgreSQL, запущенную в Docker. Приложение должно учитывать тип автомобиля (легковой, грузовой, пассажирский) и наличие загрузки (груженый/не груженый). Реализовать возможность просмотра истории всех расчетов.
